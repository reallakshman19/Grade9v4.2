# Grade9v4.2 — Six-Core Platform, Legacy Convergence and Interactive Application Migration

Grade9v4.2 converges the native six-Core curriculum architecture of Grade9v3.5 with the Work-Energy-Power (WPE), NSEJS, and R2/R3 assessment runtime foundations of Grade9v4.1 into a unified, mathematically verified, multi-subject learning platform.

## Architecture & Scope

- **Six Core Roles:**
  - `CORE1`: Canonical subject truth orientation, objects, conventions, relations, and compact transition maps.
  - `CORE1A`: Canonical inferential jumps, completed reasoning paths, bound representations, and checks.
  - `CORE1B`: Guided six-stage conceptual reconstruction (prediction → attempt → diagnosis → repair → boundary).
  - `CORE2`: Exact source custody, original questions, conditions, figures, and assistance tracking.
  - `CORE2A`: Familiar application family, explicit application cruxes, and complete reasoning routes.
  - `CORE2B`: Transfer application challenges with protected learner DECIDE moves and prior exposure comparison.
  - `EXPLORER / GCDR`: Guided Conceptual Discovery & Reasoning cognitive exploration stages.
- **Allowed Subjects:** Physics, Chemistry, Mathematics (Biology scope pending).
- **Execution Governance:** 75 bounded workpacks executed in strict dependency order per `Grade9v4.2_Execution_Kit_R4`.
